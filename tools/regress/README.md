# カメラ読み取りの試験問題（回帰テスト）

直すたびに、同じ1,260問を解かせて点数が下がっていないかを確かめるための道具です。アプリ本体では使いません。

1. `python3 gen.py` … 試験問題の画像を `_reg/` に作る（毎回同じ画像）
2. `./go.sh now` … アプリと同じ流れで全問を解かせ、`res_now.json` に保存
3. `python3 score.py now` … 種類ごとの点数を出す

ver.1.85 の点数：囲んで読む 1,182/1,240（95%）、写真全体の字の正しさ 98%

追加：`python3 gen2.py` … 口へんなど印刷の珍しい1字（124字×3）の試験問題を `_reg2/` に作る。`REG=_reg2 ./go.sh now` で解かせる。
ver.1.88 の点数：珍しい1字 96%（ver.1.87 は 83%）
